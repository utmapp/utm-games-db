About

This site collects community reports about how PC games run inside UTM.

How a game's status is decided

Each report carries a rating and the UTM version it was tested on. A game's status is taken from the reports on the newest UTM version that has any reports. Each report is one vote, and every +1 on it adds another, so a report that many people agree with outweighs several lone reports. The rating with the most votes wins and ties go to the most recent report. A single report on a newer version overrides everything on older ones.

  • Unknown — not enough information.
  • Does not launch — the game never reaches a playable state.
  • In-game issues — it runs, but with crashes, glitches or performance problems.
  • Playable — runs well enough to enjoy.
  • Plays to the end — someone completed the whole game without issues.

Auto-Triage

Games marked Auto-Triage available are handed to an automated agent that reproduces reported issues in UTM on a real test machine and attempts a fix. Read how the process works.

Data sources

Game titles, descriptions, cover art and storefront links come from IGDB.com. Only games released on PC are listed.
